# LINE 成果交付

官方帳號：ToldYou 報數據（@791vlxya）

## 會員操作

會員從自己的通話紀錄選擇成果並按「LINE 領取」，系統向 ECCAL 登記待交付工作，再顯示一次性領取碼。會員加入官方帳號，在聊天室傳送領取碼

同一次建立請求重送會取得同一筆工作與領取碼，直到開始核對。領取碼由既有服務金鑰與工作識別衍生，儲存內容為雜湊，效期與通話紀錄相同

## 有人監督的核對與發送

1. 管理者登入 [ECCAL LINE 成果核對](https://eccal.thinkwithblack.com/bdmin/voice-line/)，確認待辦所屬會員
2. 在 LINE 網頁後台讀取會員主動傳來的領取碼，記下該聊天室識別，核對準備送出的聊天室一致
3. 在 ECCAL 填入領取碼、來源聊天室與送出聊天室，勾選已核對，再取得成果連結
4. 回到同一個 LINE 聊天室，核對既有訊息後送出成果連結，讀回實際送出訊息
5. 保存送出畫面，計算 SHA-256，在 ECCAL 填入實際聊天室、送出紀錄與畫面雜湊，再登記結果

成果連結由語音站的 ECCAL 登入驗證保護，只有原會員可以讀取

## 結果與例外

| 情境 | 處理結果 |
| --- | --- |
| 正確碼、同一聊天室、人工核對完成 | 取得該工作成果連結，狀態為等待送出確認 |
| 錯碼、來源與目標聊天室不同 | 拒絕核對，不回傳成果連結 |
| 已確認 LINE 實際送出，具紀錄與畫面雜湊 | 記為成功，核銷領取碼 |
| LINE 顯示傳送失敗 | 記為失敗，保留錯誤紀錄 |
| 無法確認 LINE 結果 | 記為待確認，保留觀察紀錄 |
| 已處理的工作再次核對 | 拒絕再次派送 |
| 完全相同的結果重送 | 回傳原結果 |
| 成果更新或通話紀錄到期 | 拒絕交付過期內容 |

核對頁只開放既有營運管理者。內部服務路由驗證服務憑證，管理頁寫入驗證登入、來源與動作標頭。系統以現有 MemberRoom 儲存待辦索引，未新增 PostgreSQL 資料表、環境變數或自動 LINE 發送服務
