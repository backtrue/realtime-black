# 打電話給小黑｜產品規格 V0.3

更新日：2026-11-04。此文件記錄已確認的產品決策；未決事項不得視為既有規格。

## 1. 定位與使用者

- 「打電話給小黑」是 ECCAL 會員專用的網頁即時語音行銷顧問。
- 第一版為網頁一鍵通話，不提供一般電話號碼。
- 對外需明確標示「AI 小黑」，不是小黑老師本人正在通話。
- 使用小黑老師的說話方式與教學風格；本人聲音複製屬待完成的獨立整合。

## 2. 顧問行為與工作產出

- 會員提出問題後，AI 應先理解需求，必要時追問產品、目標、現況、數據與限制。
- 經 ThinkWithBlack MCP 選擇適用行銷方法，再提出可核對的診斷、策略與改善順序。
- 可以產出報告、廣告文案、改善計畫。
- 必須區分會員提供的事實、工具取得的資料、推論與建議。
- 第一版不允許代會員操作廣告帳號、修改外部服務或執行其他高風險寫入。

## 3. 會員與分鐘數

- 僅 ECCAL 已登入會員可開始語音通話。
- 每位會員合計提供 5 分鐘免費額度；跨多次通話累計。
- 額度須在服務端檢查與扣減，避免刷新、重複連線或多裝置超額使用。
- 免費額度用完後，未來提供購買分鐘數；第一版不開放尚未定義的付款功能。
- 從第一段實際音訊開始計時，到服務端確認通話結束為止；未接通不扣秒，工具等待時間不計入
- 每通先合計應計時間，再將總秒數向上取整。斷線到服務端確認結束之間仍依同一規則計算

## 4. 通話紀錄與交付

- 通話結束後，會員可查看該次逐字稿與摘要，從服務端確認通話結束起保存 30 天
- 付費下載通話紀錄屬未來功能；收費額度、檔案內容、與法定個資權利之區隔待定。
- 是否保留原始音檔待決，不預設錄音保存。
- 會員可要求以 Email 或「報數據」LINE 官方帳號收取報告、文案及改善計畫。
- Email：會員提供接收信箱，由系統進行經核對的成果交付。
- LINE：會員加入官方帳號並主動發送一次性領取代碼；ECCAL 建立待交付工作，Codex 協助以網頁後台核對並發送成果連結。此方案目前以有人監督的操作為前提，不預設無人值守或 Messaging API Push。
- 成果連結須透過 ECCAL 再次驗證會員，避免聊天室找錯造成內容外洩。

## 5. 真人交接

- 會員要求真人小黑接手時，經會員確認，由 ECCAL 後台建立交接案件。
- 交接內容：會員、問題摘要、已確認事實、AI 診斷、產出文件、待處理事項。
- 第一期可先規劃交接格式；完整後台處理流程列入後續階段。

## 6. 顧問資料範圍

- 第一階段不讓一般會員自行連結 Meta Ads、Google Search Console、GTM 等私人來源。
- 第一階段使用既有 ThinkWithBlack MCP 的行銷方法與會員在通話中提供的資料。
- 已預先獲得顧問客戶授權的整合，可另行規劃特殊權限；不自動向所有會員開放。
- 一般會員自助串接第三方資料列為第三階段。

## 7. 分階段交付

### 第一期：可用語音顧問

ECCAL 登入與會員隔離、5 分鐘累計額度、網頁 WebRTC 通話、Realtime 顧問式問答、ThinkWithBlack MCP 授權整合、逐字稿與摘要、成果交付流程。聲音複製待資格確認後納入驗收。

### 第二期：商業化與真人銜接

購買分鐘數、付費匯出、ECCAL 真人交接管理、已授權顧問客戶的個案資料流程。

### 第三期：進階個案數據服務

一般會員自行授權外部廣告及搜尋分析資料，執行更完整的個案分析。

## 8. 第一期驗收重點

1. 非會員、失效登入或無權限會員無法取得 Realtime 通話憑證。
2. 不同 ECCAL 會員的 MCP 授權與逐字稿完全隔離。
3. 五分鐘可跨通話累計，並有多分頁／斷線情境防護；額度控制不僅依賴前端倒數。
4. 能正常說話、插話、追問，並透過已授權 ThinkWithBlack MCP 工具產生方法化回答。
5. MCP 呼叫失敗時不將猜測內容說成查詢結果。
6. 通話後會員能讀取本人逐字稿與摘要；30 天保存期限實際生效。
7. 客戶收到的成果連結須再次驗證 ECCAL 登入權限。
8. 系統需能辨識並記錄交付成功、失敗或待處理；不得在未發送時標示成功。

## 9. 待決／待取得

- OpenAI 自訂聲音權限或替代供應商的本人聲音與延遲測試。
- ECCAL 可供此產品使用的實際身分驗證與會員權限 API 契約。
- Email 寄件服務及 LINE 網頁後台操作的可用性、權限、平台規則。
- 原始音檔是否保存、付費匯出內容、價格。
- ECCAL 真人交接後台欄位、通知與處理流程。

不在此 repository 存放會員資料、私人影音、API 金鑰或正式授權憑證。
