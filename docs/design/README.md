# 撥號介面設計交接

更新日期為 2026-11-06。這份交接包含對話中展示的兩款互動原型。

## 目前決定

使用者於 2026-11-06 選定「復古轉盤」，首頁採奶油色機身、深色轉盤與紅棕色中央撥號鍵，支援中央點按與順時針拖動

| 原型 | 外觀與操作 |
| --- | --- |
| 復古轉盤 | 奶油色機身、深色轉盤、紅棕色中央撥號鍵。可點中央撥號，也可順時針拖動轉盤。 |
| 手機直撥 | 淺綠色通話頁、人物識別、綠色電話鍵。點擊「撥給小黑」開始。 |

兩款原型都呈現待撥、撥號中、通話中、靜音、掛斷、結束摘要與通話紀錄。[復古款實作與逐項驗收](dialer-validation.md)記錄本次介面、真實資料接點與可操作的本機驗收預覽

## 現有程式接點

介面主要位於 [public/index.html](../../public/index.html)、[public/style.css](../../public/style.css) 與 [public/app.js](../../public/app.js)。

| 介面部分 | 目前接點與整合方式 |
| --- | --- |
| 會員與登入 | `membership`、`login`、`logout`。沿用 `membership()` 取得登入、資格與剩餘時間。 |
| 撥號 | `start`。將選定款式的電話按鈕接到現有開始流程。採復古款時，轉盤手勢與點按使用同一個開始入口。 |
| 狀態與提示 | `call-status`、`notice`。呈現麥克風授權、連線、錯誤及後端確認中的實際狀態。 |
| 聲音播放 | `speaker`。接回既有音訊元素及 WebRTC 播放流程。 |
| 掛斷 | `stop` 與 `end()`。沿用取消生成、清除播放、停止收音與確認通話結束的流程。 |
| 通話紀錄 | `records`、`refresh` 與 `records()`。原型右上角的紀錄入口開啟既有紀錄及成果。 |
| 成果連結 | 現有 `#call=...` 與 `#document=...`。從成果連結進站時，展開對應紀錄及文件。 |
| 靜音 | `mute` 切換目前串流中音訊軌的 `enabled`，同步更新文字與 `aria-pressed`，結束及重撥還原初始狀態。 |

保留既有 DOM 識別值可縮小改動。調整識別值時，應一併修改程式引用與相關測試。

### 與現行產品行為銜接

- 未登入、資格不足、剩餘時間為零、等待麥克風授權、拒絕授權、連線失敗及結束待確認等狀態，使用目前程式與規格定義的流程補齊畫面。
- 計費從第一段實際音訊開始，到服務端確認結束為止，工具等待時間不計入。畫面上的計時與額度顯示應配合後端判定。
- 共用行銷方法已內建，會員登入後可使用。
- 通話紀錄及成果沿用既有會員隔離、逐字稿、摘要、報告、文案、改善計畫與交付流程。
- Email 成果寄往 ECCAL 登入信箱。LINE 的領取碼、交付狀態與成果連結沿用現行規格。

## 選定外觀後的介面驗收

下列項目供實作選定款式時核對。涉及產品行為的部分須同時符合現行產品規格。

- [x] 初始主畫面可直接辨識「小黑老師／AI 行銷顧問」、會員狀態、可用時間與主要撥號操作。
- [x] 外觀、間距、配色與主要操作符合選定的原型。手機與桌面都能看清並操作主要按鈕。
- [x] 登入與額度資料來自既有後端。資格與通話狀態正確控制撥號鍵是否可用。
- [x] 撥號、接通、掛斷與失敗提示對應實際流程。連續點按與轉盤操作共用現有防重複通話機制。
- [x] 掛斷保留目前取消等待中的請求、停止收音、截斷音訊及等待後端確認的處理。
- [x] 若採用靜音鍵，操作後音軌、按鈕文字與無障礙狀態一致。結束後重新撥打使用正確的初始狀態。
- [x] 紀錄入口能查看現有逐字稿與成果，成果深層連結能開啟正確內容。
- [x] 麥克風拒絕、未接通、零額度及結束確認中的畫面都有可理解的狀態文字。
- [x] 以 320、393、768 與 1280 像素寬度檢查，主要操作可見、可點，文字可讀且頁面無水平溢出。
- [x] 鍵盤可操作撥號、掛斷、紀錄與返回。狀態提示可被輔助工具讀取，焦點移動合理。
- [x] 下列檢查完成，交付時列出實際結果與可操作的預覽。

```sh
npm run check
```

這個指令在核對基準版本中包含型別檢查、單元測試、前端測試、執行環境測試與本機打包。接手時以當前 `package.json` 為準。

前端回歸檢查可對照 [frontend.node.test.mjs](../../test/frontend.node.test.mjs)，尤其是取消後重撥、掛斷音訊、後端確認結束、成果深層連結、Email／LINE 交付狀態與登出清理。
